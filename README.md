## 技能清单

### 1. `AI-WORKFLOW.md` — 通用开发协作协议
跨项目通用的「怎么跟 AI 把话说清楚」协议：四条核心原则、四段式需求模板、
疑问优先原则、三类专用模板（新功能 / 调数值 / 修 bug）、里程碑切法、反模式表等。
**不绑定任何语言、框架、领域**，复制进任意项目即可用。
→ [查看文档](AI-WORKFLOW.md)

### 2. `CLAUDE.md` — 项目地图（示例：涂鸦街区）
项目专属信息的模板示例（一个纯代码生成的第一人称射击游戏）。
展示怎么给 AI 写一份「项目地图」：一句话定位、怎么跑、硬性约束、模块地图、架构要点、常见任务 → 改哪。
→ [查看文档](CLAUDE.md)

## 怎么用

- **新项目**：复制 `AI-WORKFLOW.md` 到项目根目录作为通用协议，再补一份 `CLAUDE.md` 项目地图。
- **两份配合**：通用协议管「怎么说」，项目地图管「项目是什么」；开工前让 AI 先读这两份。
- **持续增长**：本仓库就是我的「技能库」，后续新的规则 / 模板 / 工作流都往这里加。
