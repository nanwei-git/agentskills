界面风格规范 · Apple Liquid Glass（暗色）

适用范围：E:\webwork\vibe（Three.js 手势粒子 + 控制台）与 E:\webwork\web_work（课堂作业索引站）。视觉目标：iOS 26 Liquid Glass。

液态玻璃 折射亮环 镜面高光 连续圆角 8pt 栅格

0 · 设计系统覆盖声明（Brand Override）

本规范以 Apple Human Interface Guidelines / Liquid Glass 为真实设计系统约束，因此显式覆盖 ui-design skill 中的以下通用禁令：

通用禁令本项目处理理由
禁止 system-ui / -apple-system 字体允许且强制SF Pro 是 Apple 设计系统的本体，无法替代为第三方字体
禁止紫/靛/紫罗兰渐变禁止保留苹果风只保留单一系统蓝 #0A84FF，旧规范的粉紫 #ff9ad8 全面移除
禁止居中对称布局分场景Apple 官网式 hero 允许居中；控制台/列表沿用 Apple 左对齐 + 8pt 栅格
禁止 emoji 图标保留禁令统一使用 Lucide / Heroicons（SF Symbols 的 Web 近似）

覆盖范围仅限上述四项，其余禁令（无 emoji 图标、明确美学方向、先出设计规范后写代码）依然生效。

1 · 设计调性（Design Tone）

Apple HIG 三原则：

  • Clarity 清晰：文字在任何材质上都保持高对比；层级靠字号/字重/灰度，不靠颜色数量。
  • Deference 遵从：界面退让于内容。装饰（阴影、边框、高光）只服务于层级，不喧宾夺主。
  • Depth 纵深：玻璃材质堆叠出真实物理层次——越靠前的材质越亮、模糊越强、阴影越深。

关键词：Liquid Glass、Specular highlight、Refraction edge、Hairline、Continuous corner、Neutral shadow、Spring motion。

反模式（立即停止）

  • ❌ 彩色 box-shadow 发光（如 rgba(80,140,255,.65)）
  • ❌ 彩虹渐变标题 / clip-text 渐变文字
  • ❌ 三团偏心彩色光晕（蓝 + 紫 + 青）
  • ❌ 全大写 + 字距 .14em 的科技徽章
  • ❌ 纯黑实体面板（无模糊、无材质）
  • ❌ 生硬线性过渡（linear 或无缓动）

2 · 背景：壁纸层（Wallpaper Layer）

Liquid Glass 的折射必须建立在有内容的背景上。纯黑底上的玻璃是死的。这是与旧规范最本质的差别。

层规则
基色#000000（Apple 深色系统背景就是纯黑）
壁纸渐变2–3 团极低饱和深色氛围，明度 ≤ L 22%，例：#16233a、#1d1a2e、#101c1e
尺度大半径 radial-gradient(120% 90% at 20% 0%)，background-attachment: fixed
颗粒叠加 2–4% 不透明度噪点，消除渐变色带（banding）
禁止高饱和色块、青/粉/紫亮色光晕、多色同时出现（最多 2 个低饱和色相）
 
.wallpaper{
  position:fixed; inset:0; z-index:-1; pointer-events:none;
  background:
    radial-gradient(120% 90% at 18% -10%, #16233a 0%, transparent 58%),
    radial-gradient(100% 80% at 92% 18%,  #1d1a2e 0%, transparent 62%),
    radial-gradient(120% 100% at 50% 112%, #101c1e 0%, transparent 60%),
    #000;
}
.wallpaper::after{                 /* 颗粒 */
  content:""; position:absolute; inset:0; opacity:.035;
  background-image:url("data:image/svg+xml;utf8,<svg ... >");
}

4 · 玻璃材质规范（核心）

4.1 三段式构成

一张 Liquid Glass 表面 = 折射亮环 + 镜面高光 + 中性投影，缺一不可。

.glass{
  position:relative; border-radius:var(--r-card);
  background:
    linear-gradient(180deg, rgba(255,255,255,.10), rgba(255,255,255,.035)) ,
    var(--glass-fill);
  backdrop-filter:blur(30px) saturate(180%);
  -webkit-backdrop-filter:blur(30px) saturate(180%);
  border:.5px solid rgba(255,255,255,.14);
  box-shadow:
    inset 0  .5px 0 rgba(255,255,255,.26),
    inset 0 -.5px 0 rgba(255,255,255,.06),
    0 10px 30px -10px rgba(0,0,0,.55),
    0  2px  8px  -4px rgba(0,0,0,.35);
}

4.2 连续圆角（Squircle）

:root{ --r-card:16px; }
@supports (corner-shape: superellipse(2)){
  .glass,.card,.btn,.sheet{ corner-shape:superellipse(2); }
}

4.3 降级与兼容

@supports not ((backdrop-filter:blur(1px)) or (-webkit-backdrop-filter:blur(1px))){
  .glass{ background:rgba(28,28,30,.92); }
}

7 · 组件规范（Components）

7.1–7.10 关键规范

  • 卡片 .card：玻璃 Regular + 发丝边 + 16px 圆角；hover scale(1.015)，press scale(.985)。
  • 按钮三档：Filled（实底 #0A84FF）、Tinted（蓝 18% 填充）、Glass/Plain。
  • 分段控件 .segmented：胶囊玻璃底 + 内部滑块，spring 切换。
  • 开关 .switch：51×31px，开启 #30D158，thumb 28px 纯白。
  • 滑块 .slider：4px 胶囊轨道，thumb 28px 白圆，无外发光。
  • 列表 .list：Inset Grouped，圆角玻璃卡 + 0.5px 发丝线，行高 44px。
  • 标签 .chip：13px Footnote、--ink-2、--fill-2、胶囊、无字距。
  • 导航栏 / Tab Bar：Thick 材质，处理 env(safe-area-inset-bottom)。
  • 弹层 .sheet：22–28px 圆角，Thick 材质，底部上推 .5s。
  • 图标：统一 Lucide / Heroicons，stroke-width:1.75，无 emoji。

8 · 动效（Motion）

Token值用途
--ease-sheetcubic-bezier(.32,.72,0,1)Sheet / 大转场
--ease-stdcubic-bezier(.4,0,.2,1)通用进出
--ease-outcubic-bezier(0,0,.2,1)入场、展开
--ease-incubic-bezier(.4,0,1,1)退场、收起
  • 时长：微交互 .15–.25s；控件 .25s；转场 .35–.5s；Sheet .5s。
  • hover：scale(1.015) + 高光位移；press：scale(.97) + brightness(.94)。
  • 状态点：静态单色，活跃时 1.6s spring 极轻缩放，不做呼吸闪烁。
  • 必须支持 prefers-reduced-motion: reduce → 关闭位移与缩放。

9 · 无障碍（Accessibility）

  • 正文对比度 ≥ 4.5:1，大字 ≥ 3:1；必要时提高材质不透明度。
  • 触控目标 ≥ 44×44px。
  • 分隔线、边框不得作为唯一的信息载体。
  • 焦点可见：:focus-visible 用 2px #0A84FF 外环 + 2px offset。

14 · 一句话总纲

纯黑壁纸底 + 低饱和氛围层 + 液态玻璃材质（大模糊 + 折射亮环 + 镜面高光 + 发丝边）+ 单一 iOS 蓝强调 + 连续圆角 + 8pt 栅格 + 弹簧动效 —— 层次来自光与材质，不来自颜色与发光。
